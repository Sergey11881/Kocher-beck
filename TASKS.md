Приоритетные задачи:

## P0

1. Стабилизировать запуск основного Expo-приложения через Expo Go и tunnel.
2. Устранить расхождение Expo SDK / Expo CLI.
3. Исправить общую typecheck-проверку workspace.
4. Исключить или безопасно изолировать устаревший `kocher-beck-ios-test`.

## P1

5. Привести API к единой поддерживаемой реализации.
6. Централизовать конфигурацию API URL и добавить проверку `EXPO_PUBLIC_DOMAIN`.
7. Синхронизировать OpenAPI, сервер и generated client.
8. Улучшить диагностику сетевых ошибок и ошибок загрузки.
9. Разобраться с повторной отправкой вложений при повторе заказа.

## P2

10. Продумать защиту API и файлов.
11. Убрать базу `toolorder.db` из Git-контроля только после отдельного решения о сохранении данных.
12. Убрать архитектурное дублирование.
13. Переименовать `OrdersContext` в более точное название, если это не создаст лишних рисков.
14. Улучшить систему статусов заказа и убрать дублирование статусов.

## P3

15. Вернуться к визуальной доработке Liquid Glass.
16. История заявок и повтор заказа.
17. Улучшение карточек оснастки и фотографий.
18. Калькулятор магнитных цилиндров.
19. Вложения старых фото/чертежей.
20. Другие задачи из списка развития Kocher+Beck.
